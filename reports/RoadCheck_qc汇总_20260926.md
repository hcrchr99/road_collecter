## 5. 工具说明

```
python tools/qc.py --selftest                # 自检：合成 5 冲击信号 -> 5 事件；纯噪声 -> 0 事件
python tools/qc.py --zip <pack.zip>          # 单包体检
python tools/qc.py --all --out reports/qc    # 全量（9 包约 20s，含替代信号 20×2/包）
python replay_detect.py <pack.zip>           # 单包检测回放诊断（与 qc.py 同一实现）
```

- 检查组：meta / sampling / reproduction / periodicity / crest / missed / threshold / null_hypothesis / vision(帧质量) / physics。
- detect() 复现按 `meta.version` 分叉三套口径（≤0.6 / 0.7 / ≥0.8，≥0.8 覆盖 v0.9）。
- 视觉审计抽样扫描帧 ≤300 张/包；清晰度 = 480×360 原始灰度全图拉普拉斯方差（与诊断标定同基准）。
- 物理上界：GSD 解析式（假设 h=1m、HFOV=68°）+ 采集时段（exported_at 为 UTC，+8 换算）。

## 6. 局限（如实声明）

- 旧包（≤v0.7）复现存在分位插值边界差（≤2% 事件错位，经不应期级联放大）与 v0.3 口径未完全考证两处保留项；
  均不影响判废结论（判废依据是零假设+旧公式，不依赖精确复现）。
- 视觉审计基于 ≤300 张扫描帧抽样；GSD 依赖挂载假设参数。
- 替代信号固定种子（20260926），结果可复现；如需更强证据可加大 `--surrogates`。
