# 路面体检 RoadCheck — 众包道路健康度感知平台

用每一台手机当道路检测仪。手机固定在车把上骑行一段，应用记录三轴振动与路面画面，
AI 从中识别坑洼、减速带、井盖、裂缝与粗糙路面，众包汇聚成一张可交给市政养护部门的
道路健康度地图。

## 核心思路：为什么是两个模态

IMU 与摄像头不是重复的信息源，而是两个**正交维度**：

| 模态 | 感知的物理量 | 能识别 | 原理盲区 |
|---|---|---|---|
| **IMU** | 垂直颠簸幅度与波形 → **深度 / 结构** | 坑洼、减速带、井盖、粗糙路面 | **抓不到不引起颠簸的病害**：纵向裂缝、横向裂缝、龟裂、浅层修补。而这些在真实路面上占比极高（RDD2022 中裂缝类标注远多于坑洼） |
| **视觉** | 表面纹理与明暗结构 → **类型 / 形态** | 裂缝（可分纵向 / 横向 / 龟裂）、坑洼、粗糙路面 | 单目图像**无法可靠估计深度**；受夜间、逆光、积水反光影响 |

因此：

- 井盖与减速带在图像上只是一块区域，靠纹理很难与坑洼区分，但它们的颠簸形态是
  **结构性凸起** —— IMU 恰好能判断"这是凸起而不是凹陷"。单靠 IMU 会把井盖误判成坑洼。
- 裂缝不引起颠簸，**IMU 原理上抓不到**，只能靠视觉发现。

融合后病害类型的可识别覆盖从单模态最高的 4/7 提升到 **7/7**，坑洼的判定置信度从
0.70 提升到 0.95（双模态互证）。

一个必须做对的架构决定：**如果只在 IMU 检出事件时才抓帧，裂缝永远不会被拍到**
（不颠簸就不触发抓帧），视觉就永远只能给已发现的事件贴标签、贡献不了新增量。
所以采集端除了事件抓帧，还有**每 2 秒一次的独立周期扫描帧**。

## 快速开始

### 1. 部署采集端并采集

`collector.html` 是单文件网页应用，把它放到任意 **HTTPS** 静态托管（Vercel / Cloudflare
Pages / GitHub Pages 均可，免费）。**必须 HTTPS** —— 用 `file://` 双击打开时浏览器会拒绝
传感器与定位权限。

手机打开后按页面三步走：

1. **环境自检** —— 逐项确认安全上下文、各 API、权限状态
2. **授权并试采** —— 一次点击里同时申请定位、摄像头、运动传感器权限，然后试采 4 秒并报出实测采样率
3. **正式采集** —— 选择采集模式后开始

两种采集模式：

| 模式 | 用途 | 速度门控 |
|---|---|---|
| **骑行 / 车载**（默认） | 真实数据采集 | 8 km/h，滤除人体动作误报 |
| **手持 / 静止测试** | 室内验证信号链路 | 关闭 |

> 速度门控是必要的（否则手抖会被当成路面事件），但它依赖 GPS 速度。静止或室内时
> 速度恒为 0，门控会把**全部**事件挡掉。所以页面会在被拦截时明确提示"有 N 段振动超过
> 门限但被速度门控拦下"，并给出该切换模式的指引——而不是静默丢弃。
> **注意：测试模式只用于验证链路，产生的数据不是真实病害。**

骑行结束后，页面会列出所有检出事件并附带画面缩略图，**看着图逐条确认类型**即可。
遇到假事件（人体晃动造成）请标为「误报」——这是降低误报最有价值的负样本。

导出得到 `roadcheck_xxx.zip`，内含：

```
samples.csv    原始 IMU 序列（含时间戳、线性加速度、垂直分量、速度、坐标）
events.csv     检出的事件（含 id、峰值、时长、自动标签、人工标签）
sweeps.csv     周期扫描帧索引
meta.json      采集元信息 + 完整判定标准（detection_criteria 字段）
frames/        事件帧 ev{id}_t{ms}.jpg 与扫描帧 sweep_t{ms}.jpg
```

### 2. 跑分析流水线

```bash
pip install numpy scipy pandas scikit-learn opencv-python

# ① IMU 侧：事件检测 + 空间聚类 + 健康度指数
python analyze.py --input samples.csv --outdir out

# ② 视觉侧：事件帧判定 + 扫描帧自动发现病害
python vision.py --zip roadcheck_xxx.zip --outdir vis
#    装了 ultralytics 并在 RDD2022 上微调后，加 --weights your_model.pt 自动切换到 YOLO 后端

# ③ 融合决策：双模态互证 + 视觉独有 + 空间去重
python fusion.py --imu out/events.csv --vision vis/vision_events.json --outdir fused
```

最终产出 `fused/fused_events.geojson` —— 只含聚合后的病害点、不含原始轨迹，
可直接叠加到合规的地图底图上。

### 3. 不需要任何数据即可验证全链路

```bash
python analyze.py --selftest    # IMU：合成骑行数据，验证到健康度指数
python vision.py  --selftest    # 视觉：合成四类路面纹理，输出混淆矩阵
python fusion.py  --selftest    # 融合：决策矩阵 + 覆盖度 + 置信度单调性
python make_demo_zip.py         # 生成演示采集包 demo_pack.zip
```

## 技术要点

### IMU 侧判定标准

```
linear = 原始加速度 − 重力估计（各轴低通 τ=0.5s）
mag    = |linear|
hp     = mag − ema(mag, τ=0.5s)
smooth = ema(hp, τ=10ms)

噪声底 = quantile(|smooth|, 20%)，取最近 3 秒尾部窗口
门限   = max(1.2, 4 × 噪声底)

开始事件：速度 ≥ 8 km/h（测试模式跳过）且 smooth > 门限 且 距上次结束 > 600 ms
结束事件：smooth < 门限 × 0.5 且持续 ≥ 60 ms，或事件已达 3000 ms
```

健康度指数按**里程归一化的加权缺陷密度**计算（按绝对数量算会立刻饱和到 0）：

```
density = Σ(严重度 × 复现次数权重) / 里程(km)
RHI     = 100 × exp(-density / 15)
```

如实声明：这是面向众包感知的自研相对指标，**不能替代《公路技术状况评定标准》
(JTG 5210) 的 PCI / IRI** 等需要专业设备标定的官方指标。

### 踩过的坑（这些是本项目最有价值的部分）

1. **自适应门限的自遮蔽** —— 用滚动标准差估噪声底时，事件自身会把局部标准差抬高、
   反而把自己屏蔽掉。实测减速带峰值 3.6 把门限顶到 5.5，召回率只有 67%。
   改用 `|x|` 的 20% 分位数（事件占空比远低于此）后 100% 召回、0 误报，
   且门限倍数在 3~6 全区间稳定。见 `tune_detector.py`。
2. **经纬度单位混用** —— 同一文件里混用"千米/度"与"米/度"，使 15 m 的聚类半径
   实际变成 15 km，所有事件被并成一个点、健康度指数算成 0。
3. **物理方向搞反** —— 路面激励以垂直方向为主。把振动注入水平轴后，重力方向投影
   通道里没有信号，特征全成噪声（坑洼峰值只剩 0.05）。
4. **只在事件时抓帧，视觉就永远是装饰** —— 见上文"周期扫描帧"。
5. **绝对阈值在纯噪声上恒定误报** —— 用"低于均值 0.9σ"判暗斑，纯高斯噪声图像上
   **恒有 18% 像素满足**（正态分布的固定尾概率），平滑路面全被当成坑洼。
   改为光照归一化后做相对亮度比较 + 连通域面积过滤。
6. **Otsu 在近均匀图像上失效** —— 单峰直方图上 Otsu 会把噪声随意切开，实测把平滑
   路面 60% 的像素判成裂缝。裂缝掩码必须用固定绝对阈值。
7. **硬门控依赖不可靠的外部信号 → 静默全灭** —— 速度门控依赖 GPS，静止时速度恒为 0，
   会把全部事件挡掉且不报错。凡是"信号够了但被某条件否决"的地方都要有可见的计数器。

## 数据与合规

本项目处理位置数据，以下为硬性约束，已在实现中落实：

- **只发布聚合结果。** 系统对外只输出聚合后的病害点，**不发布任何原始轨迹**。
  原始轨迹能反推出个人出行规律与居住地，属敏感信息，本仓库以 `.gitignore` 排除
  所有采集包（`*.zip`）与本地数据目录（`userdata/`）。
- **原始数据本地优先。** 轨迹默认存在手机本地，用户可一键清空。
- **去标识化。** 不采集用户身份信息、设备唯一标识、联系方式。
- **不采集他人位置数据。** 只处理用户本人主动采集的轨迹。
- **地图底图必须使用有测绘资质的服务** —— 腾讯位置服务 / 高德 / 百度 / 天地图，
  坐标系统一用 GCJ-02。不使用境外瓦片与未经资质的地图源。
  密钥需自行申请并配置 Referer 白名单，**不得明文提交到仓库**，正式版应走后端代理鉴权。

## 数据来源与致谢

- **RDD2022**（Road Damage Dataset，CRDDC2022）：47,420 张路面图像，6 国采集，
  四类标注 D00 纵向裂缝 / D10 横向裂缝 / D20 龟裂 / D40 坑洼。含中国摩托车与
  无人机视角子集。使用请遵守其许可协议并引用原作者。
- **AsphaltObstacles**（UEA 时间序列分类库）：100 Hz 三轴加速度 + GPS，4 类，
  有官方 DTW 基准成绩 81.13%。
- **Setiawan 等** 摩托车骑行数据集（Procedia Computer Science 2022）：
  含「人体运动」与「发动机振动」两类，专用于抑制众包误报。
- 另参考 RoadSens-4M（Figshare, CC BY 4.0）、RoadSense（IEEE DataPort）、
  Road Pavement Health Monitoring（Mendeley, CC BY 4.0）。
